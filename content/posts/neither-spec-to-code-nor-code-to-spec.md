# Neither spec-to-code nor code-to-spec, but spec-bound code

* **Spec-to-code** fails in brownfield and fast-moving projects - requirements simply aren't Terraform.
* **Code-to-spec** fails because it mistakes implementation details and legacy bugs for business intent.
* **Spec-bound code** uses path-scoped rules to bind code to durable business intents and architecture decisions.
